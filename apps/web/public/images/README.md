# Illustrative tea assets

Created with the built-in image_gen tool for the local demo storefront. These are generated
illustrations in a photographic style, not photographs of the shop's actual stock.
The UI labels the shop as a demo and explains this distinction on product pages.

- tea-ritual.png: warm editorial photograph of a Yixing teapot pouring golden tea into an ivory cup,
  dark wooden tray, oatmeal linen, soft morning light, pot on the right; landscape, no text/logos.
- dark-tea.png: overhead illustrative product photograph, handmade ivory dish of twisted dark Chinese
  tea leaves, partly visible pu-er cake on warm textured paper; square, soft shadows, no labels.
- green-tea.png: overhead illustrative product photograph of rolled emerald/olive oolong leaves in
  an ivory ceramic bowl on warm stone; square, natural light and generous margins, no labels.

Final prompt set used: "photorealistic-natural" for the editorial hero and "product-mockup" for the
tea dishes; warm ivory, sage and earthy clay palette, real material texture, no people, text, logos
or watermarks. Original generated files remain in the user's Codex generated_images directory.

Files are served via next/image. Only local API image paths are currently accepted; the generated
category art is used when a real catalog image is not yet provided. No external image host is trusted
by default. The complete original generation briefs are recorded in this chat's image_gen calls.
